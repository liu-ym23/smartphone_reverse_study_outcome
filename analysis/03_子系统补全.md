  - PC_ProactiveEvents（主动事件）、PC_* 全家（PersonalContext）

  - System_QAWithSearch、System_ShowEntities、System_GetWebUrl、System_JumpAppStore、System_GetAppLatestVersion、System_DataSyncTrigger、System_InAppSearch
  - Office_KnowledgeAIAuth、Memory_Produce

## 二、AppFunction 框架（Android 16 `android.app.appfunctions`）
- `AppFunctionInvoker`：`AppFunctionManager.executeAppFunction(ExecuteAppFunctionRequest(pkg, functionId, params), executor, cancellationSignal, callback)`。
- 注册表 scheduler/impl/appfunction/registry（参数映射、DSL 转换：AppFunctionIntentMapping/CodeMapping/ValueMapping/EntityTemplate）。
- 每 pkg 开关检查（disabled → 跳过，错误码 -1）。
- 设备 system service：`app_function: android.app.appfunctions.IAppFunctionManager`（懒绑定）。
- 意义：**结构化 app 内函数调用通道**（免 GUI），与 GUI 自动化互补。

## 三、条件/定时任务系统（eventstaskmanager）
- 条件类型 6 种：**Time、Location(geofence)、Battery、Bluetooth、Wifi、Storage**（com.obric.eventkit.task.model.*Condition）。
- ConditionGroup（组合条件）+ PeriodicPolicy（周期）+ trigger_control_policy。
- 任务模型：EventTask/ConditionTask/ShortcutTask + ExecutionRecord（执行记录，云端 create_conditional_task/sweep/delete API）。
- 时间条件走 conditiontask/handler/time/AlarmReceiver（系统闹钟触发）。
- EventTask_CreateDraft/UpdateTask/SubmitTask（策略 type1+autogui）= 模型创建条件任务的工具。

## 六、PAP：嵌入式 Python 3.13 平台（memorydata 插件内，本轮重大发现）
- `com.obric.pap.base.PythonHost`：JNI native（runFile/runMain/runString）嵌入式 CPython 宿主。
- 资源：`assets/pap/packages/`（python3.13.zip=CPython stdlib+headers、numpy/psutil/pyjnius/cffi/msgpack/orjson wheels）→ 解压至 `<data>/python3.13/site-packages`。
- **控制反转架构**：30+ `I*BridgeAPI`（VectorDb/InvertedIndex/MemoryBuild/ProactiveMemory/Auditory/LifeLog/AiProactiveAgent/CaeRoute/Glass/TaskCondition/TaskProgress/SecurityGuard/Network/Store/...）是 **Java→Python 暴露的服务代理**（`__ServiceProxy` 模式 + org.jnius pyjnius）——Python 业务代码（运行时下载）通过代理调用系统能力。
- Python 业务 .py 不在静态资源中（运行时下发至应用私有目录，无 root 不可读）。
- 意义：**记忆引擎/PersonalContext 检索/主动事件等核心智能运行在端侧 Python**（numpy 向量运算 + 自研倒排索引 com.obric.search.api），而非云端。

## 十一、屏幕记忆（memorydata/screencapture）
- ScreenCaptureController：屏幕事件（tap/scroll/notification_panel_shown）→ 匹配已注册 ScreenEventReaction → generateScreenshot + generateViewTree → 入记忆库（sqlcipher）。
- 输入源：MemoryAccessibilityService（无障碍事件流）+ assist 通道。
- 即"自动记忆"功能的实现：用户操作触发被动屏幕感知，非连续录屏。
